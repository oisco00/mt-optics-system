MT옵틱스 V322 안정 패치 완성본

기준
- 현재 정상 작동 중인 no24/V317 구조를 유지합니다.
- frontend/app.js / frontend/index.html은 수정하지 않습니다.
- final-enhancements-v317.js 로딩 구조를 그대로 사용합니다.
- v318/v319 로더는 만들지 않습니다.

반영 내용
1. 수금/미수금
   - 수금등록 아래 수금내역 및 미수금내역 조회 영역 유지
   - 조회조건 추가: 시작일, 종료일, 거래처/구분 검색, 발송구분
   - 조회조건 기준으로 발송구분별 수금 및 미수금 내역 조회
   - 각 내역 기본 10건 조회, 20/50건 선택, 페이지 이동 가능
   - 합계 표시
   - 기존 하단 "발송구분별 미수금" 영역은 숨김 처리

2. 거래처/원장
   - 첫 페이지 관리 영역에서 수정 버튼 뒤 삭제 버튼 복구
   - 삭제 시 기존처럼 사유 입력 및 삭제 이력/안전 확인 로직 사용
   - 영업담당자 관리 버튼을 거래처/원장 상단에 추가
   - 거래처 등록/수정 팝업 상단에도 영업담당자 관리 버튼 추가

3. 거래명세서
   - 붉은 직인 이미지를 유지
   - 직인 크기를 현재보다 축소해 약 3/4 수준으로 조정
   - 직인 위치를 "오희숙" 우측에 맞도록 위/우측으로 조정
   - "거래명세표" 중앙 배치 및 제목 앞 세로선 제거 유지

4. 출력보고서
   - 월별판매현황을 제품명/구분/영업담당자별 금액 구조로 변경
   - 예: 제품명, 구분, 김안구, 김동열, 이영성, 사무실, 합계
   - 제품별 판매수량/판매금액/수금금액/미수금 행 구성
   - 마지막 합계 블록 구성
   - 메뉴로 복귀 버튼 추가

적용 방법
1. 이 ZIP을 mt-optics-system 루트에 압축 해제
2. Windows: APPLY_FINAL_ENHANCEMENTS_V322_STABLE.cmd 실행
3. SUCCESS 메시지 확인
4. GitHub Desktop에서 Commit / Push
5. AWS:
   cd /var/www/mt-optics
   bash ./deploy/github_update
   pm2 restart mt-optics --update-env
   pm2 save
   sudo systemctl reload nginx
6. 브라우저 Ctrl+F5

주의
- 실행 전 frontend/app.js에 final-enhancements-v318 또는 v319가 남아 있으면 중단됩니다.
- 이 경우 먼저 no24/V317 상태로 복구해야 합니다.
