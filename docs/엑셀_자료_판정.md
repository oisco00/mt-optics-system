# 엑셀 3종으로 취득 가능한 정보와 보완사항

## 검토 범위

요청하신 정확한 이름의 `거래처 정보.xls`, `판매처 원장 상세.xls`, `일별영업현황.xls` 원본 3개는 현재 전달된 파일 목록에서 직접 확인되지 않았습니다. 따라서 아래 판정은 실제 첨부된 동등 자료인 `거래처원장.xls`, `기간별 판매명세서 상세.xls`, `수금(미수금)명세서.xls`, `거래처별 영업현황 거래내역.xls`의 열 구조를 기준으로 했습니다. 새 3개 파일은 업로드 시 프로그램이 파일명과 열 제목을 다시 분석하여 판정합니다.

## 기존 첨부자료에서 확인된 정보

| 자료 | 확인된 핵심 열 | 자동 취득 가능 범위 |
|---|---|---|
| 거래처원장.xls | 거래처명, 거래일자, 거래항목, 품목, 수량, 단가, 공급가액, 매출/수금액, 잔액 | 거래처, 지역/지점 추출, 판매, 반품, 개별 수금행이 있을 경우 수금, 이월미수 |
| 기간별 판매명세서 상세.xls | 거래일자, 거래처명, 품목, 수량, 단가, 공급가액, 부가세, 합계, 담당자 | 품목별 판매·반품, 제품 기준정보, 담당자 연결 |
| 수금(미수금)명세서.xls | 거래처코드, 거래처명, 사업자번호, 전화번호, 이월미수, 매출, 수금, 현재미수 | 거래처 기본정보, 이월미수, 현재미수 대조 |
| 거래처별 영업현황 거래내역.xls | 상단 거래처명, 거래일자, 매출금액, 수금금액, 미수금 | 일별 매출·수금 합계와 미수 대조 |

## 결론

세 종류의 새 파일에 위 정보가 포함되어 있다면 거래처·판매·수금·미수금의 기본 등록은 가능합니다. 그러나 **현재 첨부 구조만으로 모든 업무정보를 정확히 확정할 수는 없습니다.** 다음 정보가 없으면 프로그램은 임의로 추정하지 않고 `기타` 또는 보완 검토목록으로 남깁니다.

- 발송구분: 택배 / 영업방문 / 기타
- 납품처·지역·지점명
- 박싱구분: 영업부 / 다빈치 / 기타
- 택배사·송장번호
- 수금방법: 카드 / 송금 / 현금
- 카드사·승인번호·은행명
- 안정적인 원본 주문번호·수금번호
- 일별 합계 파일의 품목·수량·단가 상세
- 거래처 주소, 담당 영업사원

## 자동등록 원칙

- 거래처명 괄호 안 지역은 납품처 후보로 분리합니다.
- 같은 기본 거래처명은 하나의 거래처로 연결하고 지역·발송구분은 납품처로 관리합니다.
- 발송구분이 없으면 `기타`로 등록하고 검토목록을 생성합니다.
- 수금방법이 없으면 `기타`로 등록하고 검토목록을 생성합니다.
- 수금 합계만 있고 수금일자·방법이 없으면 개별 수금으로 만들지 않고 미수금 대조 검토목록만 생성합니다.
- 일별 합계에 품목 상세가 없으면 `일별영업현황 합계(품목미상)` 임시 품목으로 등록하고 보완 검토목록을 생성합니다.
- 동일 일자·거래처·납품처·품목·수량·금액 해시와 원본번호를 이용해 재업로드 중복을 줄입니다.

## 권장 추가 열

완전 자동화를 위해 새 엑셀에 다음 열을 포함하는 것을 권장합니다.

```text
발송구분, 납품처, 지역, 박싱구분, 수금방법, 승인번호,
은행명, 주문번호, 수금번호, 영업사원, 도로명주소, 지번주소, 상세주소
```

프로그램에 포함된 `MT옵틱스_엑셀업로드_표준양식_v1.5.xlsx`를 사용하면 가장 정확하게 등록됩니다.
