MT옵틱스 APPLY_FINAL_ENHANCEMENTS_V301 적용 안내

이번 V301은 V300 수정본의 Windows CMD 인코딩 문제를 보완한 버전입니다.

핵심 변경:
1. APPLY_FINAL_ENHANCEMENTS_V301.cmd를 영문/ASCII 전용으로 재작성했습니다.
2. Windows CMD에서 한글 문장이 명령어로 오인되어 “내부 또는 외부 명령이 아닙니다”가 뜨는 문제를 제거했습니다.
3. 프런트 캐시 우회를 위해 final-enhancements-v301.js?v=301-fix1로 변경했습니다.
4. 기존 V300 기능은 유지합니다.

적용:
1. ZIP 내용을 mt-optics-system 최상위 폴더에 덮어쓰기 압축 해제
2. APPLY_FINAL_ENHANCEMENTS_V301.cmd 실행
3. SUCCESS 문구 확인
4. GitHub Desktop Commit/Push
5. AWS: cd /var/www/mt-optics && ./deploy/github_update
