# MT옵틱스 v1.5 최종 검토결과

## 1. 주소 검색

거래처와 납품처 등록/수정 화면에 주소검색 버튼을 추가했습니다. 검색 결과에서 우편번호, 도로명주소, 지번주소, 사용자가 선택한 주소, 상세주소를 각각 저장합니다. 주소서비스가 일시적으로 로드되지 않으면 저장을 진행하지 않고 인터넷 연결 안내를 표시합니다.

## 2. 엑셀 자동등록

`거래처 정보.xls`, `판매처 원장 상세.xls`, `일별영업현황.xls`를 화면에 명시하고 파일명과 열 제목을 함께 판별합니다. 기존 4종 파일명도 별칭으로 지원합니다. 업로드 전에 파일별 판별유형, 발견된 열, 누락정보를 확인한 뒤 DB 등록할 수 있습니다.

자료만으로 확정되지 않는 발송구분·수금방법·품목상세 등은 추정하지 않고 `기타` 또는 보완 검토목록으로 남깁니다. 표준양식은 프로그램 화면에서 다운로드할 수 있습니다.

## 3. 모바일 영업

PC와 별도 앱을 만들지 않고 하나의 반응형 웹앱으로 구성했습니다. 휴대폰에서는 사이드바 대신 하단 메뉴가 표시되고, `모바일 영업` 화면에서 주문 등록, 수금 등록, 거래처 조회, 최근 거래, 미수금 상위를 빠르게 사용할 수 있습니다.

## 4. 수정·삭제와 감사

주문과 수금은 수정할 수 있고, 삭제 시 사유를 반드시 입력합니다. 삭제는 DB에서 행을 없애지 않고 논리삭제합니다. 주문 삭제는 미수원장을 역분개하고 이미 출고된 재고는 복원하며, 수금 삭제도 미수원장을 역분개합니다. 수정이력에는 이전값·이후값·사용자·처리시각·접속 IP·브라우저가 저장됩니다.

## 5. 운영 보안

- 역할별 권한 분리
- 영업 사용자는 본인 등록 주문·수금만 수정/삭제
- 운영 보안값 미설정 시 서버 시작 차단
- 로그인/API 요청 제한
- 보안 헤더와 CSP
- CORS HTTPS 도메인 제한
- Excel 크기·확장자·파일 시그니처 검사
- 3000/3306 외부 비공개, Nginx 내부 프록시
- 원격 종료 비활성화

## 6. 검증 범위

JavaScript 문법검사와 쉘 스크립트 문법검사, 표준양식 구조·수식오류 검사를 수행했습니다. 이 작업 환경에는 실제 Lightsail MySQL과 npm 레지스트리 접속이 없어서 실제 DB 마이그레이션·브라우저 통합테스트는 수행하지 못했습니다. 배포 스크립트가 DB 백업, 보안 사전점검, 문법검사, PM2 재시작, Nginx 검사, 헬스체크를 순서대로 수행하도록 구성했습니다.
