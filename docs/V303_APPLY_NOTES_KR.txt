# MT옵틱스 APPLY_FINAL_ENHANCEMENTS_V303

## 보완 내용

1. 거래처 자동완성 검색/정렬 재정비
   - 입력 단어가 거래처명/거래처코드/납품처명에 포함된 자료를 우선 표시합니다.
   - 전화번호·사업자번호는 보조 검색으로만 사용하여, `1001` 입력 시 사업자번호에 우연히 포함된 다른 거래처가 먼저 뜨지 않도록 했습니다.
   - 브라우저에서 1만 건을 매번 필터링하지 않고 `/api/final/customer-suggest` 서버 조회로 전환했습니다.

2. 주소검색 근본 보완
   - IP 또는 HTTP 접속에서는 카카오 주소검색 iframe이 차단될 수 있으므로 처음부터 직접입력/주소검색 새창 모드로 전환합니다.
   - 도메인+HTTPS 환경에서는 카카오 주소검색 레이어를 사용하되, 차단/빈 화면 발생 시 직접입력으로 자동 전환합니다.

3. 조회 대기 해소
   - 고객 자동완성 서버 조회를 180ms 디바운스 방식으로 전환했습니다.
   - customers/customer_sites 검색용 인덱스를 자동 생성하도록 보완했습니다.

4. V302 기능 유지
   - 금액 `.00` 제거, 발송구분별 미수금 조건, 삭제 안전처리, 버튼 정렬 보완 기능은 유지됩니다.

## 적용

로컬 작업 폴더에 덮어쓰기 압축 해제 후 `APPLY_FINAL_ENHANCEMENTS_V303.cmd`만 실행하세요.

AWS 운영 폴더는 `/var/www/mt-optics`이며 GitHub Push 후 다음을 실행합니다.

```bash
cd /var/www/mt-optics
./deploy/github_update
```
