# 운영 보안 체크리스트

## 계정과 소스

- GitHub 저장소를 Private로 변경
- GitHub Pages와 기존 Netlify 배포 비활성화
- Lightsail은 쓰기권한 없는 GitHub Deploy key로 Private 저장소를 읽도록 설정
- `.env`, `node_modules`, `package-lock.json`, 실제 고객 엑셀은 GitHub 제외
- 대화·화면에 노출된 기존 DB/관리자 비밀번호 즉시 변경
- 사용자 비밀번호는 영문·숫자·특수문자 포함 10자 이상
- 관리자 계정은 공용으로 사용하지 않고 영업/경리/생산 사용자별 계정 생성

## 서버와 네트워크

- `JWT_SECRET` 32자 이상 무작위 값, `JWT_EXPIRES_IN=8h`
- `CORS_ORIGIN=https://order.mtoptics.net`
- `SECURITY_STRICT_MODE=true`
- `ALLOW_REMOTE_SHUTDOWN=false`
- Lightsail 방화벽은 22, 80, 443만 허용; 3000과 3306 외부 개방 금지
- SSH 22번은 가능하면 관리자 공인 IP만 허용
- Nginx가 `127.0.0.1:3000`으로만 프록시하도록 유지
- HTTPS 및 Cloudflare Access 적용

## 데이터와 감사

- 주문·수금 삭제는 사유 필수, 실제 행은 논리삭제
- 미수원장은 역분개하고 감사로그에 이전·이후 값, 사용자, 시각, IP, 브라우저 저장
- 영업 사용자는 본인이 등록한 주문·수금만 수정/삭제
- 실제 엑셀 업로드는 `imports.manage` 권한 사용자만 가능
- 엑셀은 확장자·크기·실제 파일 시그니처를 검사하지만, 신뢰할 수 있는 사내 파일만 업로드
- 매일 MySQL 백업, 정기 Lightsail 스냅샷, 복구 연습

## 배포 전 확인

```bash
cd /var/www/mt-optics
node deploy/preflight.js
npm run check
curl http://127.0.0.1:3000/api/health
pm2 status
sudo nginx -t
```

## 엑셀 라이브러리

- npm 레지스트리의 오래된 xlsx 0.18.5 대신 SheetJS 공식 0.20.3 tarball 사용
- 업로드는 인증된 관리자만 허용하며 확장자·MIME·파일 시그니처·용량을 모두 검사
